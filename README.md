# Pill Pal

PROMPT — CREAR MVP FUNCIONAL "PASTILLERO DIGITAL"

I — INTENCIÓN

Quiero construir una mini app web responsive llamada provisionalmente Pastillero Digital.

No quiero una aplicación médica compleja.

Quiero una herramienta extremadamente sencilla que ayude a una persona a responder rápidamente:

¿Qué medicamento tengo que tomar ahora?

¿A qué hora?

¿Ya lo tomé?

La aplicación debe estar especialmente diseñada para:

Adultos mayores.

Personas que toman varios medicamentos.

Personas con poca experiencia utilizando aplicaciones.

Familiares que ayudan a sus padres o abuelos a organizar sus medicamentos.

La prioridad absoluta es:

SIMPLICIDAD + CLARIDAD + ACCESIBILIDAD + FUNCIONALIDAD

No agregues funciones solamente porque sean técnicamente posibles.

La aplicación debe sentirse como un asistente personal sencillo, no como un software médico.

D — DETALLES DEL PRODUCTO

Nombre

Utiliza como nombre principal:

Pastillero Digital

Subtítulo:

Tus medicamentos organizados, a la hora correcta.

Utiliza el nombre de forma consistente en toda la interfaz.

CONCEPTO PRINCIPAL

La pantalla principal debe responder inmediatamente:

¿Qué tengo que hacer ahora?

La información más importante debe aparecer arriba.

Ejemplo:

Hola, María 👋

TU PRÓXIMA TOMA

08:00 a. m.

💊 Metformina

500 mg

[ YA LO TOMÉ ]

[ RECORDAR MÁS TARDE ]

Debajo:

MEDICAMENTOS DE HOY

07:00 a. m.
✅ Losartán — Tomado

12:00 p. m.
🔔 Metformina — Pendiente

04:00 p. m.
○ Vitamina D — Pendiente

08:00 p. m.
○ Medicamento — Pendiente

El usuario debe poder entender la pantalla sin instrucciones.

PÚBLICO Y EXPERIENCIA

Diseña pensando primero en una persona de aproximadamente 70 años que nunca ha utilizado esta aplicación.

Debe poder:

Entrar.

Entender qué hacer.

Agregar un medicamento.

Configurar su horario.

Recibir un recordatorio.

Pulsar "Ya lo tomé".

Ver que la toma quedó registrada.

Todo debe requerir el menor número de pasos posible.

Evita:

Menús complicados.

Formularios enormes.

Demasiados botones.

Lenguaje técnico.

Iconos sin texto.

Elementos decorativos innecesarios.

Animaciones excesivas.

Pantallas saturadas.

DISEÑO VISUAL

Quiero un diseño moderno, limpio, tranquilo y confiable.

NO quiero que parezca:

Un hospital.

Una aplicación infantil.

Una aplicación médica antigua.

Una aplicación llena de información.

Debe transmitir:

tranquilidad + orden + confianza + sencillez.

Paleta visual

Utiliza una combinación suave basada principalmente en:

Azul petróleo / azul profundo como color principal.

Verde suave para estados positivos.

Fondo blanco o gris muy claro.

Gris oscuro para texto.

Amarillo suave para advertencias.

Color principal aproximado:

#2F6F73

Color secundario:

#6FA8A3

Fondo:

#F7F9F8

Texto principal:

#263238

Usa los colores como referencia visual, pero prioriza siempre el contraste y la accesibilidad.

No dependas exclusivamente del color para comunicar estados.

Por ejemplo:

✅ Tomado

🔔 Pendiente

⚠️ Pendiente de atención

TIPOGRAFÍA

Utiliza una tipografía sans-serif moderna y altamente legible.

Preferiblemente:

Inter

o una alternativa equivalente si Lovable no puede utilizarla.

El texto debe ser ligeramente más grande de lo habitual.

Los elementos principales deben ser muy fáciles de leer en un teléfono.

BOTONES

Los botones deben ser grandes y fáciles de tocar.

Especialmente:

YA LO TOMÉ

y

RECORDAR MÁS TARDE

El botón principal debe destacar claramente.

Evita botones pequeños.

Evita colocar acciones importantes demasiado cerca unas de otras.

Debe ser difícil pulsar accidentalmente la acción equivocada.

Información escondida.

EXPERIENCIA MÓVIL

La aplicación debe funcionar como PWA si esto mejora la experiencia de notificaciones.
